# Km-Quick-Mybatis 功能设计文档

## 1. 文档目的

本文档说明 Km-Quick-Mybatis IntelliJ IDEA 插件对使用者提供的功能、入口和边界。内容依据当前分支代码、插件描述文件、资源、测试数据和构建配置整理，不通过 README 承载设计内容。

## 2. 产品定位

Km-Quick-Mybatis 是一个面向 IntelliJ IDEA 的 MyBatis 辅助插件，核心价值是建立 Java Mapper 接口/类、Java 方法调用与 MyBatis Mapper XML 语句之间的双向导航关系。

插件将源代码解析为可查询的本地项目缓存，并通过 IntelliJ PSI、VFS 和行标记扩展点把关联关系展示在编辑器边栏中。

## 3. 功能总览

| 功能域 | 用户可见能力 | 主要实现 |
| --- | --- | --- |
| Java 到 XML 导航 | 在 Java Mapper 类、方法或 MyBatis 调用位置跳转到 XML | `JavaLineMarkerProvider` |
| XML 到 Java 导航 | 在 `mapper`、`select`、`insert`、`update`、`delete` 标签处跳转到 Java 类或方法 | `XmlLineMarkerProvider` |
| 缓存建立 | 扫描源码根目录中的 Java/XML，解析并保存关联信息 | `MyBatisCacheManagerDefault` |
| 增量更新 | 文件修改、删除、新增后刷新受影响缓存 | VFS 监听、文件摘要扫描 |
| 手动刷新 | 刷新全部缓存、XML 缓存、Java 缓存或 Java 方法调用缓存 | Refresh Actions |
| 配置 | 配置需要识别的 SqlSession 类 | `MyPluginConfigurable` |
| 生命周期 | 项目启动加载缓存，项目关闭关闭数据库，插件卸载释放运行时资源并清理插件数据 | lifecycle 包 |
| 本地持久化 | 保存应用级配置、项目级配置、通知设置和 H2 缓存 | IntelliJ Persistent State、H2 |

## 4. 双向导航功能

### 4.1 Java 到 XML

Java 行标记提供器监听 Java PSI 元素，使用 SQL ID 查找 XML 元素。典型 SQL ID 规则为：

```text
Mapper全限定类名 + "." + 方法名
```

支持的导航场景包括：

1. Mapper 接口或类对应 XML `mapper namespace`。
2. Mapper 方法对应 XML statement 的 `id`。
3. 配置的 SqlSession 类的方法调用对应 XML statement。
4. Java 静态字符串字段和方法调用信息可作为解析结果参与缓存。

找到缓存记录后，插件通过文件路径和文本偏移量恢复 XML PSI 标签，并生成 IntelliJ 导航标记。

### 4.2 XML 到 Java

XML 行标记提供器只处理有效的 MyBatis Mapper XML，并识别：

- 根标签 `mapper`：依据 `namespace` 定位 Java 类/接口。
- 语句标签 `select`、`insert`、`update`、`delete`：依据 `namespace.id` 定位 Java 方法。

XML 文件的有效性由根标签、`namespace` 属性和 `MyBatisXmlParser` 共同判断。导航目标展示类名、方法名和所在文件信息。

## 5. 缓存与更新功能

### 5.1 缓存内容

缓存包含三类数据：

- Java 元素：类、方法、字段和方法调用，保存 SQL ID、文件路径、元素类型及偏移范围。
- XML 元素：SQL 标签、SQL 片段、结果映射等，保存 SQL ID、文件路径、标签名、`databaseId` 及偏移范围。
- 文件摘要：保存 Java/XML 文件路径和摘要，用于定时发现未通过 VFS 事件捕获的变化。

### 5.2 自动更新

- VFS 内容变化事件：文件修改或删除时，清除相关 SQL ID 的旧缓存并重新解析关联文件。
- 定时摘要扫描：默认每 5 分钟扫描源码根目录，识别新增、修改和删除文件。
- 索引未就绪时：推迟到 IDEA 进入 smart mode 后再执行解析。
- 项目关闭或项目已销毁时：停止相关运行任务并关闭数据库资源。

### 5.3 手动刷新

插件在 Tools 菜单以及编辑器/项目视图右键菜单提供刷新入口：

- 刷新所有缓存。
- 刷新 XML 文件缓存。
- 刷新 Java 文件缓存。
- 刷新 Java 方法调用缓存。

全局快捷键 `Ctrl+Alt+R` 对应全部缓存刷新动作。

## 6. 配置功能

插件设置位于 IDEA 的 Tools 配置项下，当前主要配置“需要识别的类”。配置编辑器支持：

- 通过类选择器选择继承自 `Throwable` 的类。
- 删除已选类。
- 保存和恢复应用级配置。
- 为空时使用默认 SqlSession 相关类。

默认类包括：

- `org.apache.ibatis.session.SqlSession`
- `org.mybatis.spring.SqlSessionTemplate`
- `com.kmerit.core.dao.BaseDAOMybatis`

项目级 `MyBatisSetting` 同时保存类名、方法名、字段名的命名模板，以及默认的 `select.*`、`insert.*`、`update.*`、`delete.*` 方法匹配模式。

## 7. 插件卸载功能

### 7.1 卸载时处理

插件通过 `DynamicPluginListener` 接收卸载前事件。仅当事件插件 ID 与当前插件 ID 匹配时执行处理。

卸载前首先处理运行时资源：

- 停止缓存管理器的定时调度器。
- 断开 VFS 消息总线连接。
- 清除项目级缓存管理器引用。
- 关闭已经创建且处于活动状态的数据源。

在真正卸载而非更新插件时，还清理插件产生的持久化文件：

- 项目 `.idea/quick-mybatis-settings.xml`。
- 项目 `.idea/km-quick-mybatis-notification.xml`。
- 项目 `.idea/km_mybatis_cache.mv.db` 及 H2 辅助文件。
- IDEA 应用配置目录 `options/KmQuickMybatis.xml`。

### 7.2 更新与卸载的区别

动态更新插件时保留配置和缓存，避免更新过程丢失用户设置；真正卸载插件时删除插件专属数据，避免留下无主配置和缓存文件。

## 8. 非功能目标

- 不阻塞 IDEA UI：解析、摘要计算和批量缓存操作使用读操作或后台线程。
- 项目隔离：缓存数据库和缓存管理器以项目为边界。
- 兼容 PSI 生命周期：使用 `ReadAction`、`DumbService` 和 `PsiManager` 访问 PSI。
- 可观测性：各核心组件使用 IntelliJ 日志记录扫描、解析、刷新和清理过程。
- 可恢复性：索引未就绪、文件不存在和解析异常不会直接导致插件崩溃。

## 9. 当前边界

当前实现聚焦导航和缓存，不包含 SQL 执行、数据库连接配置、Mapper XML 自动生成和业务代码生成。`AddMethodAction` 已保留为扩展点，但在 `plugin.xml` 中处于注释状态，不作为当前可用功能。
